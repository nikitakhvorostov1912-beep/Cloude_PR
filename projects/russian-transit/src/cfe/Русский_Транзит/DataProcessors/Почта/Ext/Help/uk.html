Обробка "Пошта"

Дана обробка призначена тільки для використання у вбудованому поштовому клієнтові конфігурації.

Обробкою «Пошта» реалізована головна консоль роботи з електронними листами вбудованого поштового клієнта.

При відкритті форми обробки для користувача визначається рівень доступу до облікових записів на читання електронних листів. У списку вибору облікових записів (ліва верхня частина форми) відображаються тільки доступні для перегляду і редагування облікові записи.

У дереві показуються групи листів поточного обліковому запису, при виборі перегляду всіх облікових записів, праворуч від кожної групи листів відображається обліковий запис, до якого належить поточна група листів.

Якщо для вибраного облікового запису вказана ознака використання, то під деревом груп відображається список предметів електронних листів поточної групи. Для кожної групи електронних листів можна вказати ознаку, вести облік електронних листів предметом саме в даній групі чи ні. Прапорець відображення списку предметів можна зняти/встановити в меню «Дії». Для кожного предмету в контекстному меню списку предметів можна включити ознаку прихованого предмету, а для всього списку встановити режим відображення прихованих предметів.

При активізації групи листів, по якій ведуться предмети, список предметів оновлюється. При виборі відповідного пункту в контекстному меню списку предметів можна зняти відбір списку листів по предметах. Можна проглянути всі листи по одному предмету у всіх теках електронних листів, для цього в контекстному меню списку груп листів облікового запису необхідно вибрати пункт "Зняти відбір по групі".

Листи можна перетягувати з групи в групу і з одного предмету в іншій.

Над списком листів можна побачити інформаційний рядок, який показує які обов'язкові відбори на даний момент встановлені на список листів. Обов'язкові відбори визначаються виходячи з відборів по обліковому запису, групі листів і поточному предмету. Користувач може змінювати відбори, накладати нові, але при активізації або виборі (визначається відповідною настройкою користувача) групи або предмету, відновлюються стандартні обов'язкові відбори, а додаткові знімаються.

Під списком листів відображається сам текст листа. Текст відображається у форматі HTML. Якщо лист записаний в текстовому форматі, то посилання не відображаються як гіперпосилання. Для переходу по даному посиланню для текстових листів необхідно її виділити і скористатися пунктом контекстного меню «Відкрити посилання».

Якщо у листа є вкладення, то при активізації рядка з таким листом, під списком листів з'являється кнопка, при натисненні на яку можна переглянути вкладення листа.

Користувач може швидко зареєструвати новий об'єкт в ІБ за адресою електронної пошти, перед цим провівши пошук даного об'єкту. Для цього необхідне виділити в полях «Від кого», «Кому» або «Копії» текст для реєстрації/пошуку і скористатися відповідним пунктом контекстного меню.

У кожного електронного листа є ознака розглянутості, яку користувач може змінювати або по відповідному пункту в контекстному меню списку листів, або гарячими клавішами F11 і Ctrl+F11 (встановити «Розглянуто» і встановити «Не розглянуто» відповідно). При установці режиму "Не розглянуто" для листа, з'являється вікно з пропозицією вибору дати, з якою електронний лист буде відмічений в списку листів як не розглянутий. Розглянутість листів в списку відображається відповідними  піктограмами. Якщо лист помічений як не прочитаний але дата непрочитаності вказана в документі ще не наступила, то відображається тільки піктограма не прочитаного листа. Якщо поточна дата більш ніж дата вказана в електронному листі, то крім піктограми лист виділяється в списку жирним шрифтом.

Подивитися і відновити  поточний стан режиму автоотримання/відправлення електронних листів користувача можна в меню Дії - Автоодержання/Відправка листів.

У користувача існує декілька настройок для роботи з вбудованим поштовим клієнтом:
-  Автовідкриття електронної пошти при запуску програми. У користувача при запуску конфігурації автоматично відкриватиметься форма обробки «Пошта».
-  Змінювати список електронних листів при виборі теки, а не при активізації. При достатньо великому об'ємі електронних листів, відбір списку листів при активізації теки або предмету може встановлюватися відчутно довго. При зведенні даного прапорця у користувача, відбір списку листів змінюватиметься не при активізації групи листів (одиночний клік мишкою), а при виборі (подвійний клік мишкою).
-  Одержання електронних листів при відкритті форми обробки пошти. Автоматичне отримання/відправка листів при відкритті форми обробки «Пошта».
-  Обліковий запис електронної пошти за умовчанням. Обліковий запис для користувача, що є основним обліковим записом.
-  Командний рядок для запуску зовнішнього редактора HTML-текстів. Конфігурація дозволяє для редагування текстів електронних листів у форматі HTML використовувати зовнішній редактор тексту.
