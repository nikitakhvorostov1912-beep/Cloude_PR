## Технические детали

### Почему не использовали EPF обработку APIСигма

- На длинных периодах (12+ дней) сессия Сигмы (~30 мин JWT) истекает в середине импорта
- v2.7 добавила re-auth, но в production случался DNS error на странице 38
- Прямой импорт через MCP в обход EPF — быстрее и контролируемее

### Что такое "мои дубли" и почему они появились

Изначально я фильтровал отсутствующие документы по `НЕ ПометкаУдаления`, но не учёл что ЭТАП 2 группировки в обработке помечает донорские документы удалёнными (их данные переносятся в master.ДанныеДокументов). Поэтому 1607 из моих "новых" 1789 импортов оказались дублями.

Лечится: при сверке API vs База нужно искать ГТД в `шапка ∪ ДанныеДокументов активных`, а не только в шапке.

### MCP подход (для будущих импортов)

- HTTP: `http://127.0.0.1:6010/mcp` (встроенный сервер 1С через MCP Toolkit EPF)
- Передача данных: JSON → UTF-8 bytes → Base64 → `Base64Значение()` в коде BSL
- Решает проблему экранирования кириллицы и кавычек в PowerShell here-strings
- Транспорт: `pwsh.exe 7` (нативный UTF-8 без BOM)
