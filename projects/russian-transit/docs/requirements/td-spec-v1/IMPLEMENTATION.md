## Объект 5. Обработка `ЗагрузкаРееструТД` (основная задача)

**Путь:** `src/cfe/Русский_Транзит/DataProcessors/ЗагрузкаРееструТД/`

**Реквизиты шапки:**
- `ФайлCSV` — Строка(500) — путь к выбранному файлу
- `ПериодС`, `ПериодПо` — Дата — период покрытия CSV
- `СтрокВсего`, `СтрокКомплекс`, `СтрокНовыеТД`, `СтрокТолькоОбеспечение` — Число — счётчики результата

**Табличная часть `ПредложенияКлассификации`:**
| Реквизит | Тип | Источник |
|----------|-----|----------|
| Выбрать | Булево | UI |
| Категория | Перечисление (Комплекс/ТолькоТД/ТолькоОбесп) | matcher |
| РегНомерТД | Строка(50) | CSV col #12 |
| НомерДДПТД | Строка(50) | CSV col #33 |
| Подразделение | Строка(100) | CSV col #4 |
| Декларант | Строка(250) | CSV col #15 |
| ДатаВыпуска | Дата | CSV col #28 |
| КоличествоКодовТНВЭД | Число | CSV col #45 |
| СсылкаДокумент | ДокументСсылка.ОперацияПоПоручительству | matcher (если нашли) |
| НомерСтрокиТЧ | Число | matcher (если нашли строку в ТЧ) |
| ИННПолучателя | Строка(12) | CSV col #47 |
| СтатусПроцесса | Строка(50) | CSV col #6 |
| Примечание | Строка(250) | ошибки matcher'а |

**Форма `Форма`:**
- Поле выбора файла + кнопка «Прочитать CSV»
- 3 вкладки (по полю Категория): `Комплекс` / `НовыеТолькоТД` / `БезПары→ТолькоОбесп`
- Таблица с колонками: галочка, Рег.№ТД, Номер ДДП, Подразделение, Дата, Кодов, Документ-ссылка
- Кнопка «Применить» — массовая обработка отмеченных

**Ключевые процедуры:**
```bsl
Процедура ПрочитатьCSV(Команда)
// Парсер CP1251 → заполняет ТЧ ПредложенияКлассификации

Функция СопоставитьСДокументами(СтрокиCSV)
// SELECT ДД.Ссылка, ДД.НомерСтроки ИЗ ДанныеДокументов
// ГДЕ ДД.НомерГТД В (&МассивНомеровДДП)
// Для найденных: категория=Комплекс
// Для не найденных с заполненным НомерДДПТД: категория=Проблема
// Для не найденных с пустым НомерДДПТД: категория=ТолькоТД

Процедура ПрименитьКлассификацию(Команда)
// Для Комплекс: UPDATE ДД по (Ссылка, НомерСтроки) → дозалить поля + ТипУчета
// Для ТолькоТД: CREATE новый ОПП с ВидОперации=ТДФайл
// Для строк ДД без пары в CSV: UPDATE → ТипУчета=ТолькоОбеспечение

Процедура НайтиКонтрагентаПоИНН(ИНН) Экспорт
// Lookup Справочник.Контрагенты ГДЕ ИНН = &ИНН ПЕРВЫЕ 1
// Если не найден — возвращает Неопределено + флаг «нужно создать»
```

**Скиллы:** `/epf-init` (или `/meta-compile` для обработки в расширении) → `/form-compile` → `/form-validate`

**Тесты YAxUnit:**
- Парсер CSV (кавычки, UTF-1251, разделитель, даты, запятая в числах)
- Matcher: вариант А (нашли), вариант Б (не нашли), неверный номер ДДП
- Применение: UPDATE строки + CREATE нового документа + пометка без-пары
- Граничные: пустой CSV, CSV с одной строкой, дубликаты РегНомерТД

## Объект 6. Миграционный хук

**Путь:** `src/cfe/Русский_Транзит/CommonModules/РусскийТранзитОбновлениеИБ/Ext/Module.bsl` (новый модуль или добавить в существующий)

**Процедура:**
```bsl
Процедура ЗаполнитьВидОперацииДляСуществующих() Экспорт
    Запрос = Новый Запрос(
    "ВЫБРАТЬ
    |	Операция.Ссылка КАК Ссылка
    |ИЗ
    |	Документ.ОперацияПоПоручительству КАК Операция
```

**Ожидаемый результат:** 1572 документа получают `ВидОперации = ДДПАвто`.

## Порядок реализации

```
Этап 1. Метаданные (можно параллельно)
  ├─ Объект 1: Перечисление.ВидыОперацийПоручительства
  ├─ Объект 2: Перечисление.СтатусыТранзита + ТаможенныйДосмотр
  └─ Объект 3: Реквизит Документ.ВидОперации

Этап 2. ТЧ и расчёт (зависит от Этапа 1)
  └─ Объект 4: Реквизиты ТЧ (КодТНВЭД, КолКодовТНВЭД)

Этап 3. Миграция (зависит от Объекта 3)
  └─ Объект 6: Миграционный хук (установить ДДПАвто у 1572 документов)

Этап 4. Основной функционал (зависит от всего выше)
  └─ Объект 5: Обработка.ЗагрузкаРееструТД

Этап 5. UI (зависит от Объекта 3)
  └─ Объект 7: Форма.ФормаСписка с фильтрами и условным оформлением

Этап 6. Тестирование
  ├─ BSL Lint
  ├─ YAxUnit тесты
  └─ Ручной прогон через MCP на InfoBase5
```
