## Важные выводы

1. **Колонка #33 «Номер ДДП ТД» — главный ключ matcher'а.** В 98.6% случаев она заполнена и позволяет однозначно найти существующий документ ОПП в 1С.

2. **Подразделение ≠ ТипУчета.** «Трейд Солюшнс» — наше внутреннее подразделение, не признак ТолькоТД.

3. **Колонка #45 «Количество уникальных кодов ТН ВЭД» — готовое значение для Schema 4.** Не нужно считать коды самим.

4. **В 1С НомерГТД хранится в** `Документ.ОперацияПоПоручительству.ДанныеДокументов.НомерГТД` — именно туда ищем по значению из CSV col #33.

5. **Формат номеров ТД/ДДП — 10-значный ТОРУ/дата/номер.** Разделители: `/`. Пример: `10000000/270226/0119685`.

## Парсер — особенности

- **Чтение:** `Новый ЧтениеТекста(ИмяФайла, КодировкаТекста.ANSI);`
- **Разбор строк:** `РазобратьСтрокуCSV(Строка)` — учитывает кавычки-экранирование
- **Валидация:** если col #12 (РегНомерТД) пуст → строку пропустить + предупредить Владимира
- **Дата:** формат `dd.MM.yyyy` — парсить через `Дата(Строка, "ДФ=dd.MM.yyyy")`
- **Числа с плавающей точкой:** десятичный разделитель `,` (запятая) — заменить на `.` перед парсингом
- **Кавычки:** поля вида `"ООО ""МОДА СЕРВИС"""` → убрать внешние `"` и заменить `""` на `"`
