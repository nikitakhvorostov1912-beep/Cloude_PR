# Основные стандарты кода 1С

> Источник: comol/ai_rules_1c dev-standards-core.md (адаптировано для проекта Русский Транзит).
> Используется всеми агентами написания/ревью кода 1С.

## 1. Параметры проекта (.dev.env)

Перед генерацией кода читать `.dev.env` в корне проекта:

| Параметр | Влияние |
|----------|---------|
| `{PREFIX}` | Префикс для ВСЕХ новых объектов, реквизитов, элементов форм |
| `{COMPANY}` | В шаблонах комментариев доработок |
| `{DEVELOPER}` | В шаблонах комментариев доработок |
| `{PLATFORM_VERSION}` | Доступные фичи платформы (Асинх/Ждать с 8.3.18+) |
| `{NEW_OBJECTS_IN}` | Куда помещать новые объекты: main / extension |

Для Русского Транзита: PREFIX = `РТ_`, NEW_OBJECTS_IN = `extension`, PLATFORM_VERSION = `8.3.27`.

## 2. Стиль кода

### Форматирование
- Отступ: **TAB** (не пробелы)
- Длина строки: ≤ 120 символов (при возможности корректного переноса)
- Один оператор на строку
- Пустые строки до и после блоков в условиях/циклах

### Метрики качества (жёсткие лимиты)

| Метрика | Лимит | Уровень |
|---------|-------|---------|
| Длина метода | ≤ 200 строк | hard |
| Длина метода | > 100 строк | требует разбивки |
| Вложенность | < 5 уровней | hard |
| Когнитивная сложность | < 15 | review trigger |
| Параметры метода | ≤ 5 (доп. через Структуру) | hard |

### Конкатенация строк
```bsl
// ХОРОШО: СтрШаблон()
Сообщение = СтрШаблон("Контрагент %1 не найден (ИНН: %2)", Наименование, ИНН);

// Допустимо: простой Prefix + Suffix
ПолноеИмя = Фамилия + " " + Имя;

// ЗАПРЕЩЕНО: сложная конкатенация через +
```

### Запрещённые конструкции
```bsl
Выполнить(Текст);                  // произвольный код — ЗАПРЕЩЕНО
Вычислить(Выражение);              // произвольные выражения — ЗАПРЕЩЕНО
Пароль = "secret123";             // хардкод учётных данных — ЗАПРЕЩЕНО
ТекущаяДата();                    // используй ТекущаяДатаСеанса()
?(Условие, Знач1, Знач2);         // тернарный оператор — ЗАПРЕЩЕНО (любая форма)
Если А = Истина Тогда             // сравнение с булевым — ЗАПРЕЩЕНО (писать: Если А Тогда)
Если 0 = Сумма Тогда              // Yoda-синтаксис — ЗАПРЕЩЕНО
```

## 3. Именование

- **Переменные** — отражают бизнес-смысл: `Контрагенты`, не `МассивКонтрагентов`
- **Венгерская нотация** — ЗАПРЕЩЕНА
- **Зарезервированные имена 1С** — нельзя: Документы, Справочники, Пользователи, Регистры, Метаданные, Константы
- **Префикс `Получить`** — не использовать когда тип возврата очевиден из имени
- **Булевые переменные** — только в положительной форме: `ПроверкаПройдена`, не `НеПрошлоПроверку`
- **Magic numbers** — ЗАПРЕЩЕНЫ, выносить в именованные константы
- **Порядок строковых перечислений** — алфавитный

## 4. Документирование экспортных методов

Обязательно для всех `Экспорт` процедур/функций:
```bsl
// Возвращает поручительства для организации на указанную дату.
//
// Параметры:
//  Организация - СправочникСсылка.Организации
//  Дата        - Дата - дата среза
//
// Возвращаемое значение:
//  Массив из СправочникСсылка.Контрагенты
//
Функция ПолучитьПоручительства(Организация, Дата) Экспорт
```

- Начинать с глагола: «Возвращает...», «Проверяет...», «Рассчитывает...»
- НЕ начинать с «Процедура...» или имени функции

## 5. Комментарии — что можно, что нельзя

### НЕЛЬЗЯ (шум)
```bsl
// Получаем массив контрагентов
Контрагенты = ПолучитьКонтрагентов();

// Цикл по строкам
Для Каждого Строка Из Таблица Цикл

// Возвращаем результат
Возврат Результат;
```

### НЕЛЬЗЯ — декоративные заголовки модулей
```bsl
//////////////////////////////////////////////////////////////////
// Автор: Иванов И.И. Дата: 15.03.2024  (git уже хранит это)
//////////////////////////////////////////////////////////////////
```

### МОЖНО — мотивация, контекст, ограничения
```bsl
// НДС не начисляется при экспорте, см. ст. 164 НК РФ
// Кеш: метод вызывается ~10000 раз при проведении крупных накладных
// Хак: платформа 8.3.23 возвращает некорректный тип при первом вызове
// TODO No.14752: убрать после миграции на 8.3.25
```

**Правило проверки:** "Что этот комментарий добавляет к тому что уже написано в коде?" — если ничего, удалить.

## 6. Типографика в коде

- **Буква «ё»** — ЗАМЕНЯТЬ на «е» в коде и пользовательских текстах
- **Тире «—»** — ЗАМЕНЯТЬ на дефис «-» (проблемы кодировки в логах)
- Кавычки в UI-текстах: `«...»` (гильметы)
- В строковых литералах кода: `"..."` (стандартные)

## 7. Параметры-конструкторы

Для дополнительных параметров использовать функцию-конструктор:
```bsl
Функция ПараметрыЗаполнения() Экспорт
    Параметры = Новый Структура;
    Параметры.Вставить("Дата");
    Параметры.Вставить("Валюта");
    Параметры.Вставить("ПересчитыватьСумму", Истина);
    Возврат Параметры;
КонецФункции
```

## 8. Самопроверка после каждого редактирования

После любого изменения кода — внутренняя проверка:
- Стиль и читаемость
- Корректность и граничные случаи
- Безопасность
- Конкурентность / блокировки / транзакции
- Соответствие BSL LS
